# JavaScript Problem Solving Projects

This repository contains a collection of JavaScript programs solving various problems and demonstrating fundamental programming concepts. Each file focuses on a specific problem or algorithm, which helps in understanding core programming logic and improving problem-solving skills.

## Features

- Factorial calculation
- Digit counting
- Even and odd number checks
- Leap year verification
- Array operations (merge, reverse, search, rotate, remove duplicates)
- Object iteration and key checks
- Prime number checking
- String manipulation (reverse, vowel count, longest word, palindrome)
- Mathematical operations (square, multiplication table, discount calculation)
- Random number generation
- Frequency counters
- And more
